# 機能 [![](https://img.shields.io/badge/-Features-blue)](#機能-)

## メディアサーバー
1. **複数のサーバータイプ**: Emby、Jellyfin、Plex などの人気メディアサーバーに接続できます。<br>
2. **カスタムサーバーアイコン**: メディアサーバーごとにカスタムアイコンを設定でき、複数のインスタンスを簡単に見分けられます。<br>
3. **集約ホームページ**: 視聴を続ける、最近追加、映画、テレビ番組、アニメなどを 1 か所で表示します。<br>
4. **ライブラリ全体の閲覧**: 映画、テレビシリーズ、アニメ、ドキュメンタリー、ポスターウォール、リスト表示など、メディアの種類別に閲覧できます。<br>
5. **メディアサーバー検索**: 1 つのサーバー内、または複数のサーバーを横断して同時に検索できます。<br>
6. **エピソード詳細**: ポスター、評価、あらすじ、エピソード一覧、再生進捗を表示します。<br>

## 複数のクラウドドライブ
7. **マルチプラットフォームのクラウドドライブ対応**: Aliyun Drive、Baidu Netdisk、123Pan、115 Drive など、主要なクラウドドライブサービスに対応しています。<br>
8. **WebDAV 接続**: WebDAV 経由で Quark Cloud Drive、Tianyi Cloud などに接続できます。<br>
9. **ローカルフォルダーのインポート**: ローカルフォルダーをインポートし、TMDB のメタデータを取得できます。<br>
10. **マルチアカウント管理**: 複数のクラウドドライブアカウントに同時にサインインして管理できます。<br>

## スマートメディアライブラリ
11. **TMDB メタデータの取得**: クラウドドライブとローカルファイルをスキャンし、TMDB から映画やテレビ番組のメタデータを取得します。<br>
12. **メディアの整理**: メディアファイルを分類・整理し、完全な個人用メディアライブラリを作成します。<br>
13. **統合検索**: クラウドドライブとローカルライブラリを横断して検索し、メディアをすばやく見つけられます。<br>

## ドキュメント AI
13.1 **単一ドキュメントへの質問**: 対応する PDF、EPUB、TXT、Markdown、DOCX ファイルを開いて **BoxPlayer AI / Analyze with AI** を選択すると、プレビュー内でそのドキュメントについて質問できます。<br>
13.2 **複数ドキュメントの会話**: クラウドドライブの一覧、フォルダー、検索結果から対応ファイルを選択し、最大 10 個のソースを横断して 1 つの質問ができます。<br>
13.3 **根拠のある回答**: Summarize、Key takeaways、Improve、Next steps などの組み込みプロンプトから始められます。回答にはホバーで確認できる出典の引用と、PDF の該当位置へのジャンプが含まれます。<br>
13.4 **ソースの管理**: 会話から現在のクラウドドライブを閲覧してファイルをまとめて追加したり、グローバルなファイル名検索をショートカットとして使ったり、`@filename` と入力してプロンプト内でソースを明確にしたりできます。<br>
13.5 **会話の操作**: ドキュメントのワークフローを離れずに、ワイド表示への切り替え、現在の会話のクリア、回答のコピー、回答へのフィードバック送信ができます。<br>

## 再生
14. **オンライン HD 再生**: さまざまな形式のオリジナル画質の動画を、クラウドドライブから直接再生できます。<br>
15. **複数音声トラック**: プレーヤー内で音声トラックを切り替えられます。<br>
16. **外部字幕**: 外部字幕ファイルを読み込み、字幕トラックを切り替えられます。<br>
17. **映像ストリームと画質の切り替え**: ネットワーク状況に応じて映像ストリームを切り替え、画質を選択できます。<br>
18. **再生速度の調整**: 再生速度を自由に設定できます。<br>
19. **プレイリスト管理**: プレイリストを作成・管理できます。<br>
20. **外部プレーヤー**: MPV や IINA などのプロ向けプレーヤーに対応しています。<br>

## 高速ダウンロード
21. **Aria2c ダウンロード**: マルチスレッドダウンロードに対応した高速な Aria2c エンジンを内蔵しています。<br>
22. **リモートダウンロード**: リモートの Aria2 を使って、ファイルを VPS や NAS に直接ダウンロードできます。<br>

## ファイル管理
23. **フォルダーツリー表示**: すばやく移動・操作できる専用のフォルダーツリーを備えています。<br>
24. **スマートな並べ替え**: フォルダーサイズを表示し、フォルダーとファイルをまとめて名前、サイズ、日時で並べ替えられます。<br>
25. **一括操作**: 大量のファイルや深くネストしたフォルダーを一括でリネームできます。<br>
26. **クイックプレビュー**: ファイルのすばやいコピー、動画のスプライト画像のプレビュー、ファイルの直接削除ができます。<br>
27. **大規模ファイルの処理**: 数万のフォルダーやファイルを管理し、フォルダー内のすべてのファイルを一度に一覧表示できます。<br>
28. **一括転送**: 膨大な数のファイルやフォルダーを 1 回の操作でアップロード・ダウンロードできます。<br>

## クロスプラットフォーム
29. **対応プラットフォーム**: Windows 7-11、macOS、Linux に対応しています。<br>

# Pro 版とオープンソース版 [![](https://img.shields.io/badge/-Pro%20vs%20Open%20Source-blue)](#pro-版とオープンソース版-)

BoxPlayer はコアとなるクライアントを無料かつオープンソースで提供しています。ファイル管理、メディア再生、クラウドドライブ接続、ローカルでの読書、clouddrive-cli による自動化は引き続き利用できます。Pro は主に、継続的なサーバー費用が発生するホスト型 AI 機能とアカウントサービスを対象としています。

| 機能 | 未サインイン | サインイン · 無料 | Pro |
|---|---|---|---|
| マルチクラウドのファイル管理、アップロード、ダウンロード、フォルダーツリー | — | ✅ | ✅ |
| 動画 / 音楽の再生、ローカルメディアライブラリ、メディアサーバークライアント | ✅ | ✅ | ✅ |
| ローカルの書籍の閲覧、本棚、ハイライト、メモ、ブックマーク | ✅ | ✅ | ✅ |
| clouddrive-cli / MCP Agent ツール | ✅ | ✅ | ✅ |
| BYOK · 自分のサードパーティ API キーで AI を利用 | ✅ 自分のクォータ | ✅ 自分のクォータ | ✅ 自分のクォータ |
| 組み込みの BoxPlayer AI モデル | ❌ | ❌ | ✅ 毎月のホスト型 AI クレジット |

# 新機能 [![](https://img.shields.io/badge/-%E2%9C%A8%20New%20Features-orange)](#新機能-)

> 今回のリリースでは **45 以上の大型アップグレード**を提供します。AI 読み上げ / AI 読書アシスタント / AI 翻訳 / マルチモデルチャット / 高度な音楽再生 / ダウンロード基盤 / 3 つの新しいクラウドドライブ / AI メディア整理エージェントを含みます。新しい機能はすべて、以下でモジュールごとにまとめています。

## 最近の追加: 組み込み AI、Pro アカウント、サポートチケット

1. **組み込みの BoxPlayer AI（Pro）**: 新しい `boxplayer-cloud` プロバイダーにより、Pro ユーザーは API キーを入力せずにホスト型の DeepSeek / Workers AI を利用できます。OpenAI、DeepSeek、OpenRouter、Ollama、Vercel AI Gateway、カスタム BYOK プロバイダーも引き続き利用できます。<br>
2. **共通の AI クレジットプール**: チャット、AI 検索、翻訳、埋め込み、TTS は 1 つの内部クレジットシステムを共有します。匿名ユーザーはホスト型 AI を呼び出せません。サインイン済みのトライアルユーザーには毎日少量のプールが付与され、Pro ユーザーには毎月のホスト型 AI の利用枠が付与されます。<br>
3. **ページ全体の対訳リーダー翻訳**: EPUB / PDF の読書で、原文と訳文を 1 行ずつ表示したり、原文を非表示にして訳文のみで読んだりできます。翻訳は段落ごとに順次表示され、ページをめくってもキャッシュされます。<br>
4. **リーダーのレイアウト修正**: 単ページ、見開き、スクロールの各モードを再調整し、複数段組みのテキスト、半分の幅のページ、スクロールモードのページ分割、見開きのページ分割の不具合を修正しました。<br>
5. **AI グローバル検索のアップグレード**: グローバル検索が、組み込みの AI Agent / OpenAI 互換のツール呼び出し、セマンティック検索、映画カード、クラウドドライブのリソース結果に接続されました。<br>
6. **Pro アカウントと支払いフロー**: ウェブサイトに月額 / 年額 / 買い切りの料金プラン、ホスト型の Creem チェックアウト、アプリのコールバック処理、支払い後のポーリングによるアプリ内での Pro ステータス確認が追加されました。<br>
7. **ウェブサイトのサポートチケットシステム**: `/support/` で、匿名またはサインイン済みのバグ / 機能要望のチケットを受け付けます。サインイン済みのチケットは、フォローアップのためにユーザーアカウントに紐付けられます。<br>
8. **AI 設定の再設計**: プロバイダー設定のキャッシュ、モデルの更新、組み込み AI の Pro 表示、埋め込みモデルの設定、SQLite ハイブリッド検索のオプションを、1 つの API 設定ページでまとめて管理できるようになりました。<br>

## まったく新しい「ライブラリ」 — AI を活用した個人用電子書籍リーダー

1. **AI 音声読み上げ（TTS）**: **Azure Neural TTS** と Web Speech API の 2 つのエンジンを内蔵し、数十種類の自然な音声（Xiaoxian / Xiaoxiao / Yunxi / Yunyang など）で、カーソル位置からあらゆる書籍を**章をまたいで連続再生**で読み上げます。速度 / 音声 / ピッチを調整でき、どんな電子書籍もすぐにプロ品質のオーディオブックになります。 <br>
2. **AI 読書アシスタント**: **OpenAI / DeepSeek / Zhipu GLM / Qwen / Moonshot Kimi / SiliconFlow / Ollama（ローカル） / OpenRouter / Vercel AI Gateway** など 10 以上の主要モデルにワンクリックでアクセスし、**章の要約 / 質問への回答 / 類書の推薦 / 複数ターンの会話**ができます。**ローカルの章ベクトル RAG インデックス**を備えているため、「第 3 章には実際に何が書かれている？」といった質問にも根拠のある回答が得られます。 <br>
3. **AI 単語翻訳 + 書籍全体の翻訳**: 選択して翻訳でき、**AI 翻訳（DeepL 級の品質） / Azure / Google 翻訳**、**対訳での並列読書**、**書籍全体の翻訳モード**に対応しています。どんな外国語の本もストレスなく読めます。 <br>
4. **マルチフォーマットの電子書籍リーダー**: **EPUB / PDF / TXT / MOBI / AZW / AZW3 / FB2 / DOCX / MD / HTML / CBZ / CBR / CB7 / CBT** など、主要な形式すべてに対応しています。 <br>
5. **3 つのページ表示モード**: 単ページ / 見開き / スクロールを自由に切り替えられます。新しいリリースでは「テキストが一部しか表示されず、大きな空白ができる」表示の不具合を修正し、ネイティブのページ分割とコンテナのスクロールを復元しました。 <br>
6. **クラウド + ローカルの 2 つの書籍ソース**: 接続済みのすべてのクラウドドライブで書籍を自動検出します。ローカルフォルダーをワンクリックでインポートでき、表紙 / 著者 / 出版日 / あらすじを自動取得します。 <br>
7. **プロ仕様の組版エンジン**: **Heti / Hanzi Standard Format / Chinese Web Typography Reset / Tufte CSS / Typebase** といった学術レベルのスタイルを内蔵しており、Kindle よりも優れた中英混在の組版を実現します。 <br>
8. **本棚 / お気に入り / タグ / ゴミ箱**: カード / リスト / 表紙の表示モードで、書籍のライフサイクルを完全に管理できます。 <br>
9. **メモ / ハイライト / ブックマーク / 選択メニュー**: ハイライトの色のカスタマイズ、メモの添付、ドキュメント内ジャンプ、キーボードショートカットに対応しています。 <br>
10. **注釈の一括エクスポート**: すべてのハイライトとメモを、ワンクリックで Markdown / JSON / CSV / TXT にエクスポートできます。 <br>
11. **読書統計**: 毎日の読書時間 / ページめくり数 / 読了率を可視化します。 <br>
12. **OPDS 購読**: OPDS に準拠したあらゆるオンラインライブラリを購読できます。 <br>
13. **PDF の全文検索 + 章ナビゲーション + 辞書検索 + 参考文献検索**。 <br>

## 高度な音楽再生

14. **AudioContext オーディオエンジン**: 10 バンド EQ + リバーブ + パン + ピッチシフト（速度は変えずに） + リアルタイムのスペクトラム表示。 <br>
15. **1 文字ずつのカラオケ歌詞**: Web Animations API による文字単位のハイライトアニメーションで、翻訳 / ローマ字の 2 行表示に対応しています。 <br>
16. **デスクトップのフローティング歌詞ウィンドウ**: 独立した透明な常に最前面のウィンドウで、ドラッグでき、再生に合わせてスクロールします。 <br>
17. **複数ソースからの歌詞 / カバーのフォールバック**: LRCLIB で見つからない場合、NetEase / KuGou / QQ Music / Kuwo / Migu のオープン API から歌詞とカバーを自動取得します（メタデータのみで、音声ストリームはダウンロードしません）。 <br>
18. **カスタマイズ可能なテーマシステム**: 12 色のビジュアルエディターと 15 種類の組み込みプリセットテーマを備え、すべて CSS 変数で制御されます。 <br>

## ダウンロード基盤

19. **メインプロセスでの aria2c のホスト**: PID ファイル + セッションの再開 + グレースフルシャットダウン + クラッシュ時の自動再接続。 <br>
20. **EngineClient のリアルタイムイベント**: aria2-lib による低遅延のイベント駆動で、`onDownloadStart/Complete/Error/Stop/BtComplete` を購読し、100ms 未満で状態を反映します。 <br>
21. **UPnP による自動ポートマッピング**: BT ダウンロードで NAT ポートを自動で開放し、シードの接続性を高めます。 <br>
22. **12 時間ごとの BT トラッカー自動同期**: 起動後 12 時間ごとに [ngosang/trackerslist](https://github.com/ngosang/trackerslist) から最新の公開トラッカーを取得します。 <br>
23. **Torrent ファイルセレクター**: BT タスク内の特定のファイルを選択でき、Torrent 全体をダウンロードせずに済みます。 <br>
24. **タスク詳細ドロワー**: GID / 合計サイズ / 進捗 / 速度 / シーダー / 接続数 / InfoHash / 保存先 / ファイル一覧をひと目で確認できます。 <br>
25. **ドラッグ＆ドロップでのタスク追加**: ブラウザーのアドレスバー / Finder / エクスプローラーから URL / マグネットリンク / .torrent ファイルをドロップすると、すぐにタスクを作成できます。 <br>
26. **プロトコルの関連付け**: `magnet://` / `mo://` を自動で捕捉してダウンロードダイアログを開きます（macOS の `open-url` / `open-file` に対応）。 <br>
27. **ダウンロード進捗インジケーター**: macOS の Dock / Windows のタスクバーに、リアルタイムのダウンロード進捗リングを表示します。 <br>
28. **完了時のシステム通知**: ファイルのダウンロードが完了するたびにシステム通知を表示し、クリックするとメインウィンドウにフォーカスします。 <br>
29. **一括の一時停止 / 再開 / 削除**: RPC を直接使うため、ポーリングによる遅延がありません。 <br>
30. **プラットフォーム別の aria2 設定**: darwin / linux / win32 × x64 / arm64 / armv7l / ia32 に合わせて最適化した 7 つの `aria2.conf` プロファイルを用意しています。 <br>
31. **設定の拡充**: アップロード速度の上限、シード比率、シード時間、未完了タスクの自動再開、ブラウザー拡張機能の RPC URL 表示、トラッカーエディター（1 行に 1 URL）と即時同期。 <br>
32. **スリープ防止**: ダウンロード中はシステムのスリープを防ぎます。 <br>

37. **元に戻せる操作ログ**: AI の操作はすべて `operationHistory` に記録され、ワンクリックで操作前の状態にロールバックできます。 <br>
38. **クラウドドライブ横断のツールセット**: `walkDirectory` / `renamePlan` / `movePlan` / `mediaClassifier` など、AI が呼び出せる安全なツールを内蔵しています。 <br>

# インストール [![](https://img.shields.io/badge/-Installation-blue)](#インストール-)

## パッケージガイド

`release` フォルダーには、各プラットフォームと CPU アーキテクチャ向けのインストーラーが含まれています。ファイル名のキーワードを参考に、適切なパッケージを選んでください。

### Windows

| ファイル名 | プラットフォーム | 備考 |
|--------|----------|------|
| `...-win.exe` | Windows 汎用 | システムのアーキテクチャを自動検出します。ほとんどのユーザーにおすすめです。 |
| `...-win-x64.exe` | Windows x64 | Intel / AMD の 64 ビットプロセッサー向けです。 |
| `...-win-ia32.exe` | Windows 32 ビット | 32 ビットシステムまたは古いプロセッサー向けです。 |
| `...-win-arm64.exe` | Windows ARM64 | Qualcomm Snapdragon X Elite などの ARM64 プロセッサー向けです。 |
| `...-win-x64.zip` | Windows x64 ポータブル版 | 展開して実行するだけで、インストールは不要です。 |
| `...-win-ia32.zip` | Windows 32 ビット ポータブル版 | 展開して実行するだけで、インストールは不要です。 |
| `...-win-arm64.zip` | Windows ARM64 ポータブル版 | 展開して実行するだけで、インストールは不要です。 |

**インストール方法:** `.exe` インストーラーをダブルクリックし、画面の指示に従ってください。ポータブル版の場合は、`.zip` パッケージを展開して `xbyboxplayer.exe` を実行してください。

### macOS

| ファイル名 | プラットフォーム | 備考 |
|--------|----------|------|
| `...-mac-x64.dmg` | macOS Intel | Intel チップ搭載の Mac 向けです。 |
| `...-mac-arm64.dmg` | macOS Apple Silicon | M1 / M2 / M3 / M4 チップ搭載の Mac 向けです。 |

**インストール方法:** `.dmg` ファイルをダブルクリックし、アプリを `Applications` フォルダーにドラッグしてください。インストール後に Apple Silicon でファイルが壊れているという警告が表示される場合は、次のコマンドを実行してください。

```sh
sudo xattr -d com.apple.quarantine /Applications/xbyboxplayer.app
```

### Linux

| ファイル名 | プラットフォーム | 備考 |
|--------|----------|------|
| `...-linux-amd64.deb` | Debian / Ubuntu x64 | 64 ビット Intel/AMD 上の Debian、Ubuntu および類似のディストリビューション向けです。 |
| `...-linux-arm64.deb` | Debian / Ubuntu ARM64 | ARM64 の Debian / Ubuntu 向けです。 |
| `...-linux-armv7l.deb` | Debian / Ubuntu ARMv7 | 32 ビット ARM の Debian / Ubuntu 向けです。 |
| `...-linux-x86_64.AppImage` | 汎用 Linux x64 | ほとんどの 64 ビット Linux ディストリビューション向けのポータブルパッケージです。 |
| `...-linux-arm64.AppImage` | 汎用 Linux ARM64 | ARM64 Linux 向けのポータブルパッケージです。 |
| `...-linux-armv7l.AppImage` | 汎用 Linux ARMv7 | 32 ビット ARM Linux 向けのポータブルパッケージです。 |
| `...-linux-x64.pacman` | Arch Linux / Manjaro x64 | 64 ビットシステム上の Arch Linux とその派生ディストリビューション向けです。 |
| `...-linux-aarch64.pacman` | Arch Linux ARM64 | Arch Linux ARM64 向けです。 |
| `...-linux-armv7l.pacman` | Arch Linux ARMv7 | Arch Linux ARMv7 向けです。 |
| `...-linux-x64.zip` / `arm64.zip` / `armv7l.zip` | Linux ポータブル版 | 展開して、中の実行ファイルを実行してください。 |

**インストール方法:**
- `.deb`: `sudo dpkg -i <file>.deb`
- `.AppImage`: `chmod +x <file>.AppImage && ./<file>.AppImage`
- `.pacman`: `sudo pacman -U <file>.pacman`
- `.zip`: 展開して、フォルダー内の実行ファイルを実行してください

# clouddrive-cli [![](https://img.shields.io/badge/-CLI-blue)](#clouddrive-cli-)

`clouddrive-cli` は、BoxPlayer のターミナルおよび AI Agent 向けの自動化インターフェースです。Aliyun Drive、OneDrive、Dropbox、Box、Baidu Netdisk、115 Drive、PikPak に対応しています。

主な機能:

- クラウドドライブのファイルを一覧表示し、再帰的にたどる
- Jellyfin / Emby / Plex 互換のメディアのリネームプランを生成する
- 追跡可能で元に戻せる一括リネームを実行する前に、ドライランで検証する
- ドライラン付きのアップロードプランと、クラウドドライブの整理プラン
- `clouddrive-mcp` を通じて、MCP 対応の AI クライアント（Claude Desktop、Cursor など）に同じ機能を公開する

**インストール（アプリから）:** BoxPlayer を開き、**Account Settings → Install CLI** を選択します

**単体でのインストール:**

```bash
npm install -g clouddrive-cli
```

完全なドキュメント: [clouddrive-cli/README.en.md](./clouddrive-cli/README.en.md) | [中文](./clouddrive-cli/README.md)
